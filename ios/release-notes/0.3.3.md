# Hinge Pop 0.3.3: Insert Coin

## Bubble news
- [gamecontroller.fill] Arcade has its own page now: high score, best wave, and one big Continue. {arcade}
- [flag.checkered] Every five waves is a checkpoint. Reach it once, start from it any time. {arcade}

## More
- Checkpoints have names, from Insert Coin to Kill Screen. How far up the ladder can you climb?
- The end of a run offers Continue from your checkpoint, or a fresh start from wave 1.
- Busy runs stay smooth: haptics no longer stall when the phone's vibration engine is busy.

Here's what to test:

- Like a neon cabinet that remembers your initials, Arcade should feel like a place you come back to. Does it?
- Open Arcade from Home. Does Continue start you at your furthest checkpoint?
- Play a long Arcade run with lots of popping. Does it stay smooth, with no freeze?
- Reach wave 5 for the first time. Does the end card tell you a checkpoint unlocked?
